# 심야 카페 — 게임플레이 우선 제작 순서

작성: 2026-11-02 KST. 상태: 제작 기준·작업 목록 준비 완료, 아래 신규 공정 구현 전.

## 확정한 방향과 작업 경계

- 배경 방향: 지옥의 오래된 동네, 폐업한 목욕탕을 고친 작은 심야 카페. 사신·악마·귀신이 하루 이야기를 내려놓는다.
- 플레이의 중심: 손님 이야기와 손으로 만드는 커피. 느긋하게 집고·붓고·갈고·누르고·끼우고·내어주는 과정.
- 지금 우선할 것: 재사용 가능한 조작과 커피 한 잔의 전체 연결. 새 배경 작화·캐릭터 양산·최종 UI 제작은 준비만 한다.
- 우유 첫 구현은 보존한다. `MilkCraft/README.md`, `BuildMilkCraft/MilkCraft.exe`가 기준이며 이번 준비 작업에서 수정하지 않는다. 정확한 기울임 작화와 실제 마우스 손맛 검수는 미완료다.
- Coffee Talk의 화면/코드 조사는 참고 자료다. 원작 코드·그림·소리를 우리 게임에 편입하지 않는다.

구체적 색, 카페 이름, 경제, 레시피 수는 아직 사용자 확정 사항이 아니다. 아래의 보조 기능과 수치는 구현 기본안으로 구분한다.

## 한 잔의 전체 흐름

손님 입장 → 대화/주문 → 작업대 이동 → 원두 보충 → 포터필터 받치기 → 분쇄 → 가루 정리 → 탬핑 → 머신 체결 → 컵 받치기 → 추출 → 피처 채우기 → 스팀/표면 정리 → 직접 붓기 → 받침/제공 → 마시기/반응 → 정리/다음 방문.

‘플레이 순서’와 ‘개발 순서’는 다르다. 먼저 분쇄 구간에서 공통 조작을 검증하고 그 구조를 뒤 공정에 확장한다.

## 개발 순서와 통과 기준

### G0. 조작의 공통 기반

목표: 물건 하나를 집어 유효한 자리에 놓고 다시 집을 수 있다.

- 집기/끌기/놓기, 현재 집은 물건 하나, 이동 가능한 영역, 그림의 손잡이 접점과 회전 중심.
- 유효한 위치 가까이 가면 은은한 안내와 위치 보정. 놓은 다음 물건은 슬롯을 점유한다.
- 무효한 곳에 놓으면 원래 자리로 돌아온다. 재료가 중복되거나 사라지지 않는다.
- 누르기/누르고 있기/원형 이동/회전을 구분한다. 포인터가 UI 위에 있을 때 작업대에도 동시에 입력되지 않는다.
- 시점 전환 중 입력 잠금. 포커스 상실·일시정지·창 밖 해제 때 잡기/누르기 상태 해제.
- 기본 마우스와 대체 키보드 경로 제공. 좌표는 작업대 로컬 좌표를 사용해 해상도가 바뀌어도 접점이 맞는다.

완료: 빈 포터필터를 세 번 옮겨도 위치·점유가 맞고, 잘못 놓기/화면 밖 해제/일시정지 후에도 다시 조작할 수 있다.

### G1. 첫 제작 대상 — 분쇄 스테이션

초기에는 호퍼에 원두가 준비된 상태로 공통 조작을 먼저 검증한다. 원두 보충은 G1 후반에 붙인다.

| 단계 | 플레이어 행동 | 그림/소리 반응 | 다음 단계 조건 |
|---|---|---|---|
| 빈 바스켓 집기 | 포터필터 손잡이를 잡음 | 선택 표시, 잡힌 접점 유지 | 유효한 집기 |
| 분쇄구에 받치기 | 그라인더 밑에 놓음 | 받침 위치에 정렬, 놓는 소리 | 바스켓 슬롯 점유 |
| 분쇄 시작 | 스위치를 켬 | 그라인더 회전음, 출구에서 가루 낙하 | 원두 있음+바스켓 있음 |
| 가루 받기 | 상태를 보며 분쇄를 멈춤 | 바스켓 안에 봉긋하게 쌓임, 원두 감소 | 목표량 충족 또는 수동 정지 |
| 꺼내기 | 포터필터를 작업 매트로 옮김 | 쌓인 가루를 유지 | 분쇄 정지+이동 완료 |
| 원두 보충 | 통 열기→스쿱 뜨기→호퍼에 붓기 | 원두 알갱이와 남은 양 | 호퍼 용량/잔량 반영 |

가루는 바스켓 외형과 분리한다. 내부 마스크·높이 필드·낙하 입자로 표현한다. 실제 원두량/분쇄량과 보기용 입자 개수는 구분한다. 분쇄구·가루 충돌·바스켓 위치는 같은 좌표계다.

완료: ‘받치기→갈기→멈추기→작업 매트에 놓기’가 반복 가능하고, 가루가 포터필터를 따라 이동하며 원두+가루+손실의 양이 일관된다. 바스켓 없이 켜거나 중간에 꺼낸 경우도 정의한 반응으로 끝난다.

### G2. 가루 정리와 탬핑

- 탑뷰 상세 화면에서 가루 정리 도구를 바스켓에 올리고 원형으로 돌린다. 높낮이가 점차 고르게 바뀐다.
- 탬퍼를 중심에 올려 아래로 누르면 눌린 깊이·압축 표면·작은 마찰음이 함께 변한다.
- 탬퍼를 들어 원위치에 놓아야 다음 물건을 집을 수 있다. 돌리기 도구와 눌러 다지는 도구를 구분한다.
- 압력은 누름 거리로 제어하는 게임 내 근사값이다. 실제 장비의 물리 압력 측정처럼 설명하지 않는다.

완료: 같은 포터필터에 담긴 가루가 정리·압축 상태로 이어지고, 빈 바스켓 탬핑/중복 압축/도구를 얹은 채 이동이 안전하게 처리된다.

### G3. 머신 체결과 컵 배치

- 작업대 비스듬한 시점으로 복귀. 포터필터를 그룹헤드 홈에 끼우고 손잡이를 돌려 잠근다.
- 접근 위치, 삽입, 잠금 회전은 별개 상태. 단순히 가까이 놓았다고 추출 준비가 끝나지 않는다.
- 컵을 트레이에 놓고 추출구와 맞춘다. 잠금 전 컵 배치도 허용하되 양쪽 조건이 갖춰져야 펌프를 켤 수 있다.
- 체결되지 않은 손잡이는 빠지고, 체결된 손잡이는 허용된 방향의 풀기 조작만 받는다.

완료: 컵/체결 조건 없이 추출되지 않고, 맞춰 끼우고 돌릴 때 시각·소리·상태가 동시에 맞는다.

### G4. 에스프레소 추출

- 스위치 → 펌프 시작 → 초기 방울 → 두 줄기 → 컵에 쌓이는 커피/크레마 → 정지 → 마지막 방울.
- 추출량과 크레마는 컵의 데이터로 저장한다. 다른 작업 위치로 옮겨도 같은 내용물이다.
- 추출 시간은 ‘스위치가 켜진 동안’으로 계산하고, 클릭을 놓았다는 이유만으로 다음 공정에 넘기지 않는다.
- 잘못 놓인 컵/추출 중 이동/빈 원두/그룹헤드 잠금 해제에 대한 반응을 정한다. 초기 구현은 위험한 조작을 부드럽게 막는 방식.
- 기본안: 시간제한 없음, 적정 추출량 안내와 자동 정지 보조. 실제 바리스타 재현 수치는 이후 별도 조율.

완료: 정상 시작/수동 정지/자동 정지/중도 취소에서 액체가 복제되지 않고 마지막 방울 뒤 컵을 안전하게 옮길 수 있다.

### G5. 우유 준비

- 우유 통을 기울여 빈 피처를 채운다. 우유는 별도 액체이며 내부 마스크로 가린다.
- 스팀 완드를 넣고 켜면 표면 움직임·김·스팀 소리가 바뀐다. 온도와 거품 상태를 게임용 수치로 관리한다.
- 종료 후 완드를 빼고, 피처를 가볍게 두드리거나 돌려 표면을 정리한다.
- 잔량과 공기/거품 표현을 구분해 우유가 이유 없이 늘지 않게 한다. 첫 버전은 단순한 거품 상태만 사용.

완료: 피처 채우기부터 스팀 종료까지 연결되고, 빈 피처/완드 밖 작동/과열 보조가 안전하게 처리된다.

### G6. 기존 직접 붓기 시험 장면 통합

- `MilkCraftModel`을 공정이 소유한 피처/컵 데이터에 연결한다. 새 240ml 피처를 매번 몰래 만드는 초기화 코드는 제거한다.
- 추출한 에스프레소 컵과 데운 우유 피처가 같은 물건으로 이어진다.
- 이동/앞으로 기울이기/잔량/줄기/착수/넘침/마지막 방울/완료를 연결한다.
- 먼저 섞이고 채워지는 동작을 검증한 후, 높이·유량·이동에 따른 흰 무늬를 추가한다. 에칭과 정교한 라테 아트 평가는 후순위다.
- 2.5D 기울임은 임시 표현으로 표시한다. 자세별 실루엣과 주둥이·마스크 교체는 작화 준비 목록을 따른다.

완료: 컵을 빗나가거나 피처를 세웠을 때도 총량이 맞고, 새 공정에 들어갈 때 커피/우유가 초기화되지 않는다.

### G7. 제공·손님 반응까지 한 바퀴

- 컵을 받침에 놓고 손님 쪽으로 밀어 준다. 제작 결과의 컵 색/무늬가 제공 화면으로 이어진다.
- 최소 한 손님의 대기→컵 보기→잡기→마시기→반응 포즈. 손/컵/입 접점과 김·마시는 소리를 연결한다.
- 보상은 한 번만 지급하고 다음 주문 또는 방문으로 넘어간다.
- 기본안: 큰 실수 벌점과 빠르기 경쟁을 완화한다. 서툰 한 잔도 진행 가능하게 하고 재시도 선택권을 둔다. 경제 수치 확정은 별도.

완료: 입장부터 제공·반응·다음 방문까지 실제 실행 파일에서 완주하고, 중간 저장/재시도/일시정지에서 막히지 않는다.

## 코드 구조 변경 준비

현재 `CafeState`는 `Grind→Extract→Milk`이며 분쇄 2초 누르기와 추출 3초 품질 평가가 섞여 있다. 이 시간을 그대로 늘리는 방식으로 확장하지 않는다.

| 구성 | 책임 | 적용 계획 |
|---|---|---|
| 방문 진행 | 입장·대화·주문·반응·보상·저장 | 기존 CafeState에서 공정과 분리 |
| 제작 진행 | 현재 작업과 허용되는 다음 행동 | 별도 CraftSession/CraftStage 도입 |
| 물건 상태 | 위치·점유·가루·추출액·우유·온도 | Tool/Container 데이터, 단일 소유자 |
| 조작 | 집기·이동·놓기·누르기·돌리기 | 공통 입력/Grab/Slot 규칙 |
| 공정 계산 | 분쇄·정리·압축·추출·스팀·붓기 | 각각 독립 모델, 렌더링과 분리 |
| 화면 | 파츠·마스크·출구·접점·시점·효과 | 기존 CafeView를 단계적으로 분리 |
| 오디오 | 시작·반복·강도·종료 | 공정 이벤트로 재생, 재진입 중복 방지 |

처음부터 모든 기존 스크립트를 교체하지 않는다. G0/G1 전용 장면→검증→후속 공정→G7 연결 순서로 진행하고 기존 실행본은 유지한다.

## 힐링 플레이 기본안

시간제한·손님 인내심 감소·실패 게임오버는 첫 구현에 넣지 않는다. 잘못 놓으면 되돌려주고, 다음 행동은 물건 근처에 짧게 안내한다. 성공 소리와 실제 물건 변화로 상태를 알린다. 되풀이되는 공정은 충분히 직접 해본 뒤 보조/간소화 선택을 추가한다. 대화 중 강제로 분쇄 소음이나 제조 화면이 끼어들지 않도록 장면 흐름을 관리한다.

## ‘완료’라고 말할 기준

- 각 단계가 움직이는 작화/입력/소리/상태를 함께 갖춘다. 그림만 또는 숫자만 있으면 미완료.
- 전체 과정 정상 완주와 단계별 취소·재시도·해제·포커스 상실·해상도 변경 검사.
- 원두/가루/액체 총량, 공정 순서, 슬롯 점유, 한 번만 주는 보상 검사.
- 개발자 자동 실행 검사와 사람이 직접 조작하는 검수를 분리해 기록한다. 자동 검사만으로 손맛 완료라고 하지 않는다.
- 기본형을 3회 연속 막힘 없이 만들고, 실수 경로에서도 다시 완성할 수 있어야 G7 완료.
- 마지막으로 실제 원본 크기의 정지 화면과 동작을 확인한다. 시간만 통과한 버튼 게임으로 공정을 대체하지 않는다.

## 바로 다음 구현 작업

G0/G1의 작은 구간부터: 빈 포터필터 집기 → 분쇄구에 받치기 → 분쇄 스위치 → 가루 쌓임 → 정지 → 작업 매트에 놓기. 이 구간이 통과하기 전 목욕탕 배경 대량 제작이나 후속 미니게임 병렬 구현을 시작하지 않는다.
