# Grinding station implementation plan

상태: 실행 준비, 구현 전. 기준: `docs/GAMEPLAY_ROADMAP_2026-11-02.md` G0/G1. 새 테마의 최종 작화는 보류하고 직접 제작 플레이를 먼저 검증한다.

후속 결과: 준비된 호퍼에서 집기→받치기→분쇄→매트 이동의 첫 실행본을 구현했다. 모델 검사 818개 확인 항목과 네이티브 자동 입력 3회 완주 통과. `GrindStation/Build/GrindStation.exe`, `GrindStation/Review/native-result.json` 참조. 아래 전체 체크리스트에는 원두 보충과 실제 OS 마우스 검수 등 미완료 항목이 남으므로 G0/G1 전체 완료로 표시하지 않는다. 파일 분리 변경과 검수 한계는 `GrindStation/IMPLEMENTATION_NOTES.md`에 기록했다.

## 목표

임시 작업대에서 포터필터를 집어 분쇄구에 놓고, 스위치를 작동하여 가루를 받은 뒤 작업 매트로 옮긴다. 같은 바스켓의 가루 상태가 이동 중에도 보존돼야 한다.

## 제약

Unity 기존 프로젝트에 전용 시험 장면과 새 파일을 추가한다. CafeState/CafeController를 즉시 전면 교체하지 않는다. MilkCraft 파일/빌드와 원본 그림은 보존한다. 최종 UI·목욕탕 배경·손님 양산·새 플러그인 설치는 이 작업에 포함하지 않는다. 기본 조작 범위에 맞는 파츠만 확인한다.

## 예정 파일과 역할

| 예정 경로 (UnityProject 기준) | 책임 |
|---|---|
| Assets/Scripts/Crafting/CraftItemState.cs | 물건 ID·위치·점유 슬롯·내용물 |
| Assets/Scripts/Crafting/CraftInteraction.cs | 집기·이동·놓기·해제·보정 |
| Assets/Scripts/Crafting/GrindModel.cs | 원두→가루 전환, 용량, 멈춤, 부족/넘침 |
| Assets/Scripts/Crafting/GrindStationController.cs | 모델과 입력을 연결하는 전용 장면 제어 |
| Assets/Scripts/Crafting/GrindStationView.cs | 앞뒤 파츠·마스크·낙하 가루·표면 표시 |
| Assets/Editor/GrindStationBuild.cs | 기존 메인과 별도 실행본 빌드 |
| Assets/Scenes/GrindStation.unity | 전용 검수 장면 |

아래 경로는 아직 생성하지 않은 계획이며 필요에 따라 작은 단위로 조정한다. 파일명이 확정된 구현이라고 보고하지 않는다.

## 작업 1 — 상태/계산부터 검사

- [ ] C# 독립 검사에서 슬롯 중복 점유, 두 물건 동시 잡기, 무효 놓기 복귀를 실패 사례로 작성.
- [ ] 분쇄 시작 조건, 원두 부족, 바스켓 용량, 중도 정지, 바스켓 제거, 총량 보존, 다른 프레임 간 유량을 검사.
- [ ] 예상한 실패를 확인한 뒤 데이터/모델을 구현하고 통과시킨다.
- [ ] 가루량과 표면 높이 데이터의 관계를 명시한다. 보기용 입자를 양의 원본 데이터로 사용하지 않는다.

## 작업 2 — 집기/놓기 시험 장면

- [ ] 하나의 포터필터와 분쇄 받침/작업 매트 두 슬롯으로 시작.
- [ ] 집는 접점 유지, 근접 보정, 무효 놓기 복귀, 슬롯 해제를 연결.
- [ ] 시점/해상도 변경, UI 중복 입력, 포커스 상실, 일시정지, 창 밖 해제를 검증.
- [ ] 실제 마우스 조작 검수와 개발자 자동 입력 검수를 구분해서 남긴다.

## 작업 3 — 가루 받기

- [ ] 호퍼는 처음에 채워 둔다. 스위치 시작/정지와 분쇄 루프 소리 연결.
- [ ] 가루가 출구에서 떨어져 바스켓 마스크 안에 쌓이게 한다. 위치가 맞지 않으면 낙하를 가짜로 바스켓에 순간 이동시키지 않는다.
- [ ] 분쇄 중 바스켓 제거의 기본안은 안전 정지. 남은 공중 가루는 낙하 후 정리한다.
- [ ] 바스켓을 옮길 때 쌓인 가루가 함께 이동하는지 확인.
- [ ] 이어 원두 통/스쿱으로 호퍼 보충을 붙인다. 보충 전용 파츠가 없으면 미완료로 기록한다.

## 작업 4 — 실제 실행본으로 검수

- [ ] 정상 한 바퀴와 3회 반복, 잘못된 자리/빈 호퍼/가득 찬 바스켓/중도 해제 검사.
- [ ] 가루 받기 전/중/후와 작업 매트 이동의 사진·동작 기록.
- [ ] 시작/반복/정지 소리와 물건 가림/접점 확인.
- [ ] 상태 검사·실행 검사·직접 조작 검사 결과와 남은 작화 한계를 문서화.
- [ ] 통과한 뒤 G2 가루 정리/탬핑 구현으로 넘어간다.

## 공정 값을 정할 때

첫 버전의 그램 수·분쇄 속도·보정 거리·가루 높이·적정 압축 깊이는 튜닝값이다. 실제 장비의 정확한 시뮬레이션을 약속하지 않는다. 사용자에게 보이는 행동과 결과의 연결, 멈췄을 때의 반응, 재시도 가능성을 먼저 검증한다.
