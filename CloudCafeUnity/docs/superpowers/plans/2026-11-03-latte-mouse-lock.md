# 우유 붓기 마우스 고정 수정

사용자 승인: 게임 클릭 시 마우스 고정, 손을 포인터로 사용, 피처와 붓기 위치를 함께 이동, Esc 해제. systematic-debugging 스킬 적용 승인.

원인: 절대 화면 좌표 차이로 움직이면서 OS 포인터를 가두지 않아 창 끝에 닿으면 이동이 끊겼다. AssistedAim은 이동을 65%로 줄이고 표시 좌표만 제한해 내부 목표와 실제 위치가 달랐다.

수정: 우유 단계 클릭 잠금/상대 입력/화면 방향 변환, 실좌표 원형 제한, 축소 보정 제거, Esc/포커스/종료 해제. 일반 제작 화면은 클릭 후 창 내부 제한. 손 커서는 기존 손잡이 투영 위치를 사용하며 별도 화살표를 숨긴다. 기존 실행본을 보존하고 CoffeeCraftLatteMouse로 별도 빌드.

검증: 회귀 검사에서 기존 .5 이동이 .325로 축소되어 실패하는 것을 확인한 뒤 수정. 위치 검사 5개 및 우유 모델 188개 통과. 최종 빌드와 단독/전체 자동 검사 통과. 초기 단독 검사 타이밍 실패를 모델의 누적 계산 시간에 맞춰 보완했다. 실제 OS 입력 인수는 캡처 도구 검은 화면 때문에 미완료.
