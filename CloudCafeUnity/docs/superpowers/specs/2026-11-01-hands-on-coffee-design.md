# 손으로 만드는 라테 — 제작 설계

작성일: 2026-11-01. 상태: 구현 전 검토안.

## 목적
기존 Unity 카페의 그림과 손님 대화를 유지하며, 원두부터 제공까지 실제 도구를 직접 조작하는 편안한 제작 경험을 만든다. 사용자가 요청한 모든 공정을 포함한다.

## 화면과 접근 방식
권장: 카페 메인 화면에서 작업대 확대 화면으로 들어간다. 작업대에서는 손잡이와 추출구가 보이는 비스듬한 시점을 사용하고, 가루 표면·탬핑·라테 아트를 다룰 때만 위에서 보는 화면으로 전환한다. 서로 다른 시점의 그림을 같은 도구인 것처럼 단순 회전하여 대체하지 않는다.
대안: 전체를 정면에서 진행하면 가루 표면 조작이 잘 보이지 않는다. 전체를 탑뷰로 진행하면 머신 체결과 추출구가 가려진다. 혼합 시점을 제작 제안으로 채택하며 사용자 최종 확인 전이다.

## 제작 순서와 조작
1. 원두 통을 열고 스쿱으로 원두를 떠서 그라인더 호퍼에 기울여 붓는다.
2. 빈 포터필터를 집어 분쇄구 아래 받침에 놓는다.
3. 그라인더 스위치를 누르면 가루가 흘러 바스켓 안에 쌓인다. 원두 잔량과 분쇄량을 함께 갱신한다.
4. 평탄화 도구를 바스켓에 올리고 원을 그리며 돌린다. 표면 높낮이가 줄어든다.
5. 탬퍼를 올리고 아래로 눌러 압축한 뒤 들어 올린다. 누름 깊이와 눌린 표면이 보인다.
6. 포터필터를 머신 홈으로 옮겨 끼운 뒤 손잡이를 돌려 잠근다. 가까운 위치는 부드럽게 맞춰 준다.
7. 컵을 추출구 밑에 놓고 스위치를 누른다. 초기 방울, 두 줄기 추출, 크레마, 종료 후 방울을 구분한다.
8. 우유 통을 기울여 피처를 채운다. 피처를 스팀 완드로 옮겨 우유를 데운 뒤 내리고 가볍게 두드리거나 돌려 표면을 정리한다.
9. 추출한 컵을 작업 위치로 가져온다. 피처를 높이 들어 섞고, 낮추어 흰 거품을 올린 뒤 앞으로 이동하여 마무리한다.
10. 컵을 받침에 놓고 손님 쪽으로 밀어 제공한다. 손님 반응과 저장은 기존 진행에 연결한다.

## 편안함을 위한 제안
시간 제한과 실패 게임오버를 두지 않는다. 근접한 도구는 제자리에 맞춰 주고, 잘못 놓으면 재료를 잃지 않고 돌아온다. 추출과 스팀에는 적정 상태 표시와 자동 종료 보조를 둔다. 흘린 양은 표현하되 큰 벌점을 주지 않는다. 기존 속도 중심 점수·보상은 완성 및 손님 반응 중심으로 조정한다. 이 항목들은 제작자 제안이다.

## 그림·움직임·소리
기존 도트 배경과 컵·피처 분리 파츠를 재사용한다. 원두 통/뚜껑/스쿱, 호퍼, 분쇄구, 포터필터의 옆·윗면과 체결 자세, 평탄화 도구, 탬퍼, 머신 스위치·그룹헤드·스팀 완드, 우유 통, 받침의 사용 가능한 독립 파츠를 확인하고 부족한 것만 추가한다. 액체와 가루는 용기 내부 마스크로 자른다. 잔량·낙하 가루·커피 줄기·스팀·표면 변화는 코드로 만든다.
원두 낙하, 분쇄 반복음, 평탄화 마찰, 탬핑, 체결, 펌프, 스팀, 따르기, 잔 내려놓기 소리를 각 행동의 시작/지속/종료에 연결한다. 실제 음원 확보 여부를 구현 시 확인하며 임시음은 임시로 표시한다.

## 코드 변경 범위
CafeState의 Grind→Extract→Milk 세 단계를 위 공정 상태로 확장한다. CafeController는 집기·끌기·놓기·누르기·원형 이동을 처리한다. CafeView는 도구별 위치, 접점, 회전 중심, 가림 순서와 공정별 시점을 표시한다. CafeUi는 현재 행동 안내와 접근성 보조만 담당한다. 기존 도움말, 손님 대화, 다음 날 및 저장 기능을 유지한다.

## 완료 조건
실제 플레이에서 모든 공정을 건너뛰지 않고 연결한다. 잘못된 순서·놓는 위치·포인터 해제·화면 밖 이동에도 진행이 멈추거나 재료가 복제되지 않아야 한다. 원두·가루·우유 양은 보존한다. 각 단계의 화면 캡처와 시작부터 제공까지 실행 검증을 남긴다. 그림과 소리가 빠진 단계는 완료로 보고하지 않는다.
