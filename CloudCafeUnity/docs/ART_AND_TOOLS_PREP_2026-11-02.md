# 지옥 목욕탕 카페 — 작화·도구 준비표

작성: 2026-11-02 KST. 준비 문서이며 새 배경 작화, 신규 플러그인 설치, 외부 유료 호출은 실행하지 않았다.

후속 변경: 사용자 추가 승인 후 DOTween Free를 설치·설정하고 에디터 동작 검사를 통과했다. 위 ‘미설치’ 상태는 이 문서 최초 작성 시점이다. 현재 상태는 `PLUGIN_DECISIONS_2026-11-02.md`를 따른다. 외부 유료 호출/구매는 없었다.

‘플러그인을 전부 준비’는 작업에 필요한 기능과 담당 도구를 매핑하는 의미로 정리했다. 관련 없는 도구를 전부 설치하지 않는다. Unity에 추가할 외부 패키지는 현재 없음. Spine·DOTween·유료 유체 패키지가 설치됐다고 가정하지 않는다. 먼저 내장 기능과 기존 분리 에셋으로 G0/G1을 검증하고, 부족한 기능이 확인될 때만 도입한다.

## 보관할 세계관 제작 묶음

확정: 지옥 동네의 폐목욕탕을 고친 심야 카페, 일상적인 초자연 손님.

제작 제안: 빛바랜 청록 타일, 호박빛 조명, 구리 배관, 매표소 카운터, 사물함, 흐린 유리, 멀리 지나가는 붉은 전차. 실제 팔레트/가게 이름은 미확정.

| 제작 묶음 | 준비할 내용 | 착수 조건 |
|---|---|---|
| 메인 카페 | 벽/바닥/카운터/창·문/사물함/배관을 분리, 손님 좌석 접점 | G1 조작·작업대 크기 확정 후 배경 한 컷 검토 |
| 작업대 | 그라인더·매트·머신·컵의 간격, 손잡이 이동 범위 | G0/G1에서 임시 배치로 먼저 검증 |
| 손님 | 대기·피곤·말하기·컵 보기·잡기·마시기·반응 | G7의 첫 사신 한 명부터 |
| 분위기 효과 | 배관 진동·창밖 전차·문 종·김·잔잔한 실내음 | 기본 플레이를 가리지 않는 위치/볼륨 검토 후 |
| 최종 UI | 대화·작업 안내·레시피·접근성 | 조작 검증 후 사용자와 디자인 선택 |

## 공정 작화 발주 규칙

그림을 요청하기 전에 파일마다 캔버스 크기, 픽셀 단위, 시점, 앞뒤 파츠, 투명 영역, 내부 마스크, 회전 중심, 집는 위치, 슬롯/출구/손 접점을 고정한다. 실루엣이 달라지는 기울임은 XY 평면 회전만으로 처리하지 않는다. 코드 액체·가루·줄기·양 표시를 용기 그림에 합쳐 그리지 않는다.

G1 필수 파츠: 호퍼/뚜껑, 분쇄구 앞뒤, 스위치 켬/끔, 포터필터 몸체·앞테두리·내부 마스크, 작업 매트, 원두 통·스쿱. 첫 구간은 현재 파츠로 임시 조립하고 부족한 파일만 발주한다. 기존 scene_data의 cup/pitcher 마스크를 다른 용기에 그대로 재사용하지 않는다.

## 오디오 발주 단위

물건 집기·놓기, 원두 낙하, 분쇄 시작/반복/정지, 가루 정리, 탬핑 접촉/해제, 체결, 펌프 시작/반복/정지, 마지막 방울, 스팀, 붓기, 잔 제공, 마시기, 문 종. 반복음은 공정 강도와 연결하며 정지/일시정지/장면 전환에서 남지 않아야 한다. 임시 생성음과 최종 음원을 분리 표기한다.

다음 실행은 게임플레이 문서의 G0/G1이다. 이 준비 문서만으로 새 스킬 실행·유료 생성·새 플러그인 구매가 완료됐다고 보고하지 않는다.
